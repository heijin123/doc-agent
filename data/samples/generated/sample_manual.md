# DocAgent 测试手册

## 产品简介

DocAgent 是一款文档智能助手，支持 PDF、Word、Excel、PPT 等常见办公格式。

## 安装说明

运行 pip install docagent 即可完成安装，需要 Python 3.13 及以上版本。

```python
# 这行在代码块里看起来像标题，但不应被当成章节标题
def hello():
    return "world"
```

### 环境变量

需要配置 DASHSCOPE_API_KEY 才能使用向量化功能。

## 故障排查

遇到网络超时请检查代理设置。
